# 데이터 업로드 가이드

매일 KPI 분석에 필요한 데이터를 이 폴더에 드롭하면 됩니다. 구글 시트 URL로 줘도 OK.

---

## 1. 매출 데이터 (필수)

각 채널의 주문 export를 그날 폴더에 드롭하거나, 누적 시트 URL을 알려주세요.

```
data/raw/2026-05-27/
├── imweb-orders.xlsx        (자사몰)
├── smartstore-orders.xlsx   (스마트스토어)
├── coupang-growth.xlsx      (쿠팡 그로스, 있으면)
├── coupang-wing.xlsx        (쿠팡 윙, 있으면)
└── ozzip-orders.xlsx        (오집, 있으면)
```

**필수 컬럼**: 주문번호, 주문일시, 주문자ID(or 이메일/전화), 결제금액, 제품명, 수량, 주문상태

**제품명은 원가 시트의 제품명과 일치**시켜주시면 자동으로 (채널 × 제품) 매칭 → 정확한 객당 기여이익 계산이 됩니다.

## 분석 요청 방법

파일 드롭 후 채팅창에 이렇게:

> "5/27 KPI 분석해줘"

또는:

> "오늘 데이터 분석 + 대시보드 업데이트"

자동으로 처리되는 것:
1. 파일/시트 읽어서 KPI 7종 계산
2. `data/processed/kpi-history.json`에 그날 데이터 append
3. `dashboard/2026-05-27.md` 일별 상세 리포트 생성
4. Git 커밋 + 푸시 → Vercel 자동 배포

## ⚠️ 주의

- 파일명에 한글 OK
- 폴더명은 `YYYY-MM-DD` 형식
- 민감 정보(고객 이름·연락처)는 분석 후 익명화 저장
- 구글 시트로 주시면 매번 파일 다운받지 않아도 되니 더 편함
